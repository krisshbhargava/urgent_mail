Bug Report Prioritization with Modern NLP

Classifies software bug reports into two categories:
  - Failure Impact Type (5 classes: user-facing bug, crash, performance, security, feature request)
  - Action Urgency Type (4 classes: no action, low urgency, needs attention, immediate)

Dataset: Mozilla/Eclipse bug reports (Lamkanfi et al., MSR 2013), 2000 issues.
Labels generated by Claude Sonnet 4.6, validated on a 200-issue human-annotated sample.

Setup
    python3 -m venv venv
    source venv/bin/activate
    pip install pandas scikit-learn matplotlib torch transformers accelerate sentencepiece protobuf

Run in order
    python3 1_data_split.py         splits data into train/dev/test
    python3 2_label_quality.py      AI vs human label agreement (fill in bugs_sample_200.csv first)
    python3 3_majority_baseline.py  majority class baseline
    python3 4_tfidf_lr.py           TF-IDF + Logistic Regression baseline
    python3 5_deberta.py            fine-tune DeBERTa-v3-base
    python3 6_modernbert.py         fine-tune ModernBERT-base
    python3 7_results.py            print comparison table and save results/summary.json

Results (test set, macro F1)
    Failure Impact Type:   Majority 20.8% / TF-IDF 63.4% / DeBERTa 59.9% / ModernBERT 66.3%
    Action Urgency Type:   Majority 27.8% / TF-IDF 70.1% / DeBERTa 72.4% / ModernBERT 69.2%

Files
    bugs_classified.csv       2000 bug reports with AI-generated labels
    bugs_sample_200.csv       200-issue sample for human annotation
    results/summary.json      all model metrics
    results/joint_eval.json   joint accuracy across both tasks
